How health is calculated

Each accessible workspace metadata response, Admin inventory, Core inventory, known capacity SKU, nonempty workspace, workspace description, and enabled artifact description check has equal weight.

Score = passed checks / all checks in assessed workspaces. Unknown checks do not pass; workspaces not yet scanned are excluded. Review coverage before interpreting the score.

Missing description fields are unknown, not assumed empty. An empty workspace is flagged only when both inventories succeeded. Unassigned capacity is not classified as unknown SKU. A paid capacity is not a health failure.

Health groups: scan errors first, then unknown evidence, then failed checks (needs review), otherwise healthy by these checks. This is not a Microsoft governance score or certification.

About this utility

Independent localhost administration utility for Microsoft Fabric: tenant discovery or optional CSV scope, user-provided trial-capacity assignment, metadata backup/restore and confirmation-protected cleanup.

Dashboard scope is either all workspaces returned by the signed-in tenant's Admin API or saved CSV workspace IDs. Item access still depends on permissions. Counts are observed metadata, not usage analytics. No stale-item detection, storage-size measurement, automatic archiving, ownership validation or automatic deletion is implemented.

Authentication, dashboard snapshots, settings and activity remain in memory. Signing out, expiry or restarting the server clears this session.
